# Internationalization (i18n) - NACHO Vehicle Inspection

Bilingual French (default) / English. French is primary; English is secondary. No page mixes both languages on one render.

## 1. Strategy: session locale + single URLs

- The active locale is stored in the **session**, defaulting to `fr`.
- Public pages use **single clean URLs** (no `/fr` or `/en` prefix). The same URL renders in whichever language the session holds.
- `GET /language/{locale}` (locale in `fr|en`) sets the session locale and redirects back.
- A `SetLocaleFromSession` middleware applies the locale on every public request.

See ADR 002 in [adr/](adr/) for the decision and its SEO trade-off (also covered in [SEO.md](SEO.md)).

## 2. Static interface text

Stored in Laravel translation files under `lang/fr/` and `lang/en/`, grouped by domain, e.g.:

- `navigation.php` - menu labels, buttons
- `home.php` - homepage section copy (**Step 6** — in use)
- `components.php` - reusable UI strings (hero, trust, forms, cards)
- `footer.php`, `branding.php` - footer and logo alt text
- `forms.php` - field labels, placeholders, consent text
- `validation.php` - validation messages (override Laravel defaults as needed)
- `messages.php` - success/error/flash messages
- `tariffs.php` - Master Pricing Console: matrix headers, result card CTAs, regulatory section, logistics strip, FAQ Q&A ([FRONTEND.md](FRONTEND.md))
- `footer.php` - footer text
- `admin.php` - admin UI labels (where translated)

Views reference keys via `__('home.hero_title')` etc.

## 3. Dynamic content

Database-driven content is stored in both languages via `_fr` / `_en` columns ([DATABASE.md](DATABASE.md)):

- service titles/descriptions/SEO
- center descriptions
- blog posts (title/excerpt/content/SEO)
- career posts (title/description/requirements)
- legal/static pages (title/content/SEO)
- tariff names/descriptions (`name_*`, `description_*`), validity display labels
- tariff logistics strip (`site_settings` keys `tariff_logistics_*`) — admin-overridable; FAQ may use `tariffs.php` or future CMS blocks
- media alt text

Models expose accessors that return the column for the active locale, **falling back to French** when the English value is empty (documented in [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md)).

## 4. Language switcher

- Displayed as `FR | EN` in the header/top bar.
- Selecting a language hits `GET /language/{locale}`, updates the session, and returns to the current page rendered in the chosen language.
- The active language is visually indicated.

## 5. Formatting

- Currency shown as FCFA with thousands separators (e.g. `17 900 FCFA`).
- Dates formatted per locale where helpful.

## 6. Rules

- Every public page has a complete translation in both languages.
- Never render mixed-language content on a single page.
- New translatable UI strings must be added to both `lang/fr` and `lang/en`.
- New translatable DB content must provide both `_fr` and `_en` (English may fall back to French until translated).
